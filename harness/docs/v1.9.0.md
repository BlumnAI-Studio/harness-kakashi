# v1.9.0 — 정원지기 네이밍 (카카시 → 정원지기) + 플러그인 2.1.0 출시

**날짜**: 2026-09-09
**유형**: Minor (메타 에이전트 페르소나 개편 + config 스키마 1.2.0 + 마더 정원에 Mode F 적용)

---

## 한 줄 요약

정원을 가꾸는 메타 에이전트의 사용자 노출 이름이 **카카시 → 정원지기**로 통일됐다.
배포 플러그인은 명령을 `/harness-creator`, `/harness-chakra`로 단축해 **2.1.0**으로 출시했고,
마더 정원은 새 스킬의 **Mode F(migrate)** 를 자기 자신에게 적용한 첫 사례가 됐다.

**동작은 하나도 바뀌지 않았다. 바뀐 것은 이름과 문구다.**

---

## 배경

카카시는 이 하네스의 첫 은유였다 — 직접 싸우지 않고 제자를 배치하는 스승, 사륜안으로 술법을 복사하는 카피 닌자.
하지만 v1.5.0 이후 정원 은유(햇빛·영양분·물길, 꽃을 심다/피우다, 별지기·지도지기)가 하네스의 중심 서사로 자라났고,
사용자 도움말에 "카카시 하네스", "정원지기 카카시", "사륜안 발동"이 섞여 나오는 것이 오히려 진입 장벽이 됐다.

결정 (사용자 확정, 2026-09-09):
- 정원을 가꾸는 **정원지기** 개념으로 메타 에이전트를 재정의한다 — 정원지기 = 카카시
- 사용자에게 노출되는 도움말·가이드에서는 **정원지기**로 통일한다. "카카시"라는 단어를 새로 노출하지 않는다
- **프로젝트명·설치명은 유지**한다 — `harness-kakashi`, `harness-kakashi@harness-kakashi-skills`, `$schema: "kakashi-harness"`. 이름이 아니라 주소이기 때문에
- 지침(CLAUDE.md 등)에 "카카시로 작동하는 규칙"이 남아 있을 수 있으므로 **하위 호환** — 카카시 규칙은 정원지기 규칙으로 해석
- 기존 버전에서 업그레이드하면 **리네이밍이 될 수 있도록** 마이그레이션을 지원

### 마이그레이션 설계 원칙

1. **자동 실행 금지** — 활성화 시 구 네이밍이 감지되면 안내 한 줄만 덧붙이고 요청된 모드를 계속한다
2. **기록물 불변** — `harness/logs/`, `harness/docs/v*.md`의 '카카시' 표기는 역사이므로 바꾸지 않는다
3. **사용자 편집 보존** — `tamer.md`에 사용자가 추가한 절차/평가축은 남기고 은유 문장만 교체
4. **지침은 목록만 보고** — CLAUDE.md 등의 잔여 참조는 스캔·보고만 한다. 그대로 두어도 동작한다(정원지기 = 카카시)

## 변경 사항 — 마더 정원 (1.8.0 → 1.9.0)

마더 정원은 2.0.x 이전 `init` 하네스와 같은 처지였으므로, Mode F 절차를 그대로 밟았다.

### 1. `harness/harness.config.json`
- `$schemaVersion`: 1.0.0 → **1.2.0**
- `name`: "Kakashi's Harness" → **"정원의 하네스 — 마더 정원"**
- `version`: 1.8.0 → **1.9.0**, `lastUpdated`: 2026-09-09
- `plugins.harness-kakashi.skills`: `["harness-creator", "harness-chakra"]`

### 2. `harness/agents/tamer.md` — 조련사 → 정원지기
- 마더 tamer.md는 배포 템플릿과 역방향 drift 상태였다("조련사 (Tamer)", 정원 은유 없음 — 2.0.0 로그의 미해소 잔여).
  이번에 배포 템플릿(정원지기 페르소나·"나는 누구인가"·세 겹 토양)과 정렬하면서 마더 고유의 별자리 섹션은 보존
- `persona: 정원지기` 추가, 구 명칭(조련사/정원지기 카카시) 명시

### 3. 안내 문서
- `harness/docs/README.md` — 호출 방법(`/harness-creator`, `/harness-chakra`) 신설, 별자리에 v1.5~v1.9 추가
- `harness/docs/agents-and-evaluation.md` — 트리거 예시 명령 갱신
- `harness/knowledge/lore/naruto-worldview.md` — **lore는 보존**. 상단에 이름 규칙(원형 카카시 ↔ 노출 명칭 정원지기) 주석 추가, 차크라 스킬 경로 갱신

## 의의

**은유가 하나로 모였다.** 하네스는 정원, 에이전트는 꽃, 지식은 햇빛, 엔진은 물길 — 그리고 그 정원을 가꾸는 이는 정원지기다.
카카시는 사라진 것이 아니라 세계관(lore)의 원형으로 남았다. 정원지기가 누구를 닮았는지는 [[naruto-worldview]]가 기억한다.

> 이름을 바꾸는 일은 기능을 바꾸는 일보다 조심스럽다 — 기록은 남기고, 지침은 존중하고, 주소는 지킨다.
