**날짜**: 2026-05-09
**유형**: Minor (새 에이전트 + 새 엔진 + 새 운영 원칙)

---

## 변경 요약

[[sai|🖌️ 사이 (묵화 닌자)]]가 영입됐다 — Konohagakure 출신 묵화 닌자, 두루마리 그림이 살아 움직이는 술법 **超獸偽畫(초수의화)** 의 사용자.
이 영입으로 카카시 하네스에 **design-first 원칙**이 도입된다 — 펜슬 디자인(.pen)이 단일 정전(canon), harness-view 코드는 그 그림자.

사이의 직속 다음 공정은 [[chizumori|🗺️ 치즈모리 (지도지기)]]다. **사이가 그리고, 치즈모리가 보여준다.**

---

## 영입 배경

v1.6.0에서 치즈모리를 영입하며 harness-view를 GitHub Pages로 퍼블리싱하기 시작했다.
v1.6.1에서 md 모달·위키링크·mermaid를 추가하며 시각 자산이 풍부해졌다 — 그러나 **시각의 진실(canon)이 코드에만 있는** 상태였다. 색·간격·타이포가 PR마다 미세하게 흔들렸고, 새 페이지 추가 시 일관성을 유지하기 어려웠다.

`Home/design/harness-view.pen` 펜슬 디자인이 그려지면서, 정전을 **그림 자체**로 옮길 수 있게 됐다.
이를 운영 규칙으로 굳히려면 **그리는 일을 전담하는 닌자**와 **그것이 살아나게 하는 술법**이 필요했다.

5. **Phase 4** 코드 동기화 (HTML/CSS/JS)
6. **Phase 5** 정합성 점검 (Aligned / Drift)
7. **Phase 6** 치즈모리 인계

## 새 원칙 — design-first

| 핵심 명제 | 의미 |
|-----------|------|
| **단일 정전 (Single Canon)** | `.pen` 이 진실, 코드는 그림자 |
| **그리고 살린다 (Draw-then-Animate)** | 디자인 갱신이 코드 갱신보다 항상 앞선다 |
| **부채 회수 (Debt Recovery)** | 코드가 정전을 임시로 앞서 갈 수 있으나 다음 사이클에서 회수 |

부채 운용 (`harness.config.json` `design.debtPolicy`):
- 라벨: `design-debt:` (커밋/PR 메시지)
- 7일 이상 미회수 → 정원지기 경고
- 30일 이상 → 다음 마이너 릴리스 차단

상세: [[design-first|⚖️ design-first 원칙 정전]]

## 정원지기 평가축

- 워크플로우 개선도: **A** — 시각 정전 부재 → 단일 정전 도입; PR마다 흔들리던 일관성을 디자인 단계에서 보장
- Claude 스킬 활용도: **5/5** — Pencil MCP, Read/Write/Edit, harness-kakashi-creator 협업
- 하네스 성숙도: **L5 → L5+** — 시각 도메인까지 정전화 완료, knowledge/agents/engine 3계층 모두 갱신

## 사이 평가축 (신규 도입)

- 디자인-코드 정합성: **Aligned** — 첫 정전 수립 직후
- 단일 정전 준수: **Clean** — design-debt 0건
- 컴포넌트 재사용성: **Reusable** — 사이드바를 reusable 컴포넌트로 분리, 9개 페이지가 인스턴스로 사용

## 치즈모리 평가축

- 지도 정합성: **OK** — 매니페스트는 다음 sync 시 갱신
- 빌드 멱등성: **Idempotent** (변경 없음)
- 정적/동적 분리: **Clean**
