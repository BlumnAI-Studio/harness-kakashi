## 변경 요약

[[chizumori|🗺️ 치즈모리(지도지기)]]가 그리는 [[v1.6.0|harness-view]]에 세 가지 기능을 추가했다.
모두 정적/동적 분리 원칙([[chizumori]] §3) 위에서 작동한다 — 새로 복제하는 본문은 0건.

### 1. 🪟 md 모달 뷰어 (mdview popup)

기존: `[[hoshimori]]` 의 별자리 footer에 있는 `.md` 링크를 클릭하면 GitHub Pages가 raw `.md` 를 그대로 보여줘 가독성이 0이었다.
예) `https://psmon.github.io/harness-kakashi/harness/agents/sage-deming.md`

신규: 뷰 내부에서 `.md` 링크를 클릭하면 **모달 팝업**이 열려 marked로 렌더링된 본문을 보여준다. ESC, 오버레이 클릭, 닫기 버튼으로 종료.

- 컴포넌트: `Home/harness-view/js/components/md-modal.js`
- 상단 액션: `↗ raw` (원본 보기) · `GitHub` (소스 링크) · `✕` 닫기
- 모달 본문은 **동일한 파일을 fetch** 해서 렌더 — 복제 없음
- 외부 링크, `target="_blank"`, cmd/ctrl+click 은 그대로 통과

### 2. 🌟 위키링크 자동 해석

호시모리가 모든 문서에 부착한 별자리 footer의 `[[name]]` / `[[name|alias]]` 위키링크가 이제 **클릭 가능**하다.

- 동작: 뷰 부팅 시 `indexes/{agents,knowledge,engine,docs,logs}.json` 합쳐 name → repoRelPath 사전 구축
- 매칭된 별: `<a class="wikilink" data-md-modal="path">` 로 변환 → 클릭 시 mdview 모달 오픈
- 깨진 별(매칭 없음): `<span class="wikilink-broken">⚠ name</span>` 으로 회색 처리 (원문 보존)
- 모듈: `Home/harness-view/js/utils/wikilinks.js`

### 3. 🌊 Mermaid 다이어그램 지원

`.md` 본문 안의 ` ```mermaid ` 코드 블록을 SVG로 자동 렌더한다.

- 참조 패턴 (AgentZeroLite md-viewer) 흡수: marked custom renderer가 mermaid 블록을 `<div class="mermaid">` 로 변환
- HTML 엔티티 디코딩 (marked v4가 `-->` 를 `--&gt;` 로 escape하는 회귀 수정)
- 모달 + 본문 뷰 모두에서 작동
